# Tutuma Float Phone 1.8.1

本项目基于小笼包老师的 **AI Virtual Phone** 原始项目，并在 **MOMO（末末）老师的二次开发版本**基础上继续开发。

本版本对部分原有内容进行了取舍与调整，持续优化交互体验和移动端适配，整体更偏向 **Android 端的便捷操作与使用习惯**。

## 项目来源

- **原始项目 · 小笼包**：[ai-virtual-phone](https://github.com/xiaolongbao0709/ai-virtual-phone)
- **二次开发 · MOMO（末末）**：[momo.float.phone](https://github.com/jianchu-in/momo.float.phone)
- **三次开发 · Tutuma Float Phone**：基于 MOMO 二改版本继续开发与完善。

## 关于本版本

本仓库用于整理与分享三次开发成果。具体新增功能、修改内容及 App 使用方法，将在分享版功能确认后单独整理。

本项目并非从零开发；原版、二改及其他贡献者的成果归属于对应作者。发布前将核对并保留适用的开源许可证、版权声明及第三方素材授权信息。

- 移入原版 `test` 分支的去壳布局、设备判断、大屏缩放及旧浏览器缩放回退；外观设置新增“显示形态”，屏幕形态可选择标准、沉浸全屏或显示系统状态栏。保留分享版原有字号和组件间距设置。

- 单人／群聊语音、视频通话中的语音合成或播放失败时，显示小提示，可重试该句；加载期间不额外弹错误提示，重试不会重新生成台词。

验证命令：`node scripts/check-share-shell-speech.cjs`、`node scripts/check-share-lock-startup.cjs`、`node scripts/check-android-tts.cjs`、`npm run typecheck`、`npm run android:web`。

## 1.7.1 更新日志（包含 1.7 累计改动）

本次更新整合了 1.7 以来的功能新增、记忆系统优化和问题修复。

### 1. 跨 App 记忆系统

- 完善 Chat、短信、电话、LYSN、Weverse、iCity、X 等应用之间的记忆共享与衔接。
- 优化短期、长期及核心记忆的读取机制，减少重复内容和上下文混乱。
- 修复短信陌生号码身份混淆、电话记录重复及通话结果不完整的问题。
- 完善直播、日记、动态、多人互动等事件的记忆归属及时间判断。
- 优化角色之间的知情权限，避免无关角色读取其他人的私人经历。
- 完善部分原始事件的删除联动，已删除的来源不再进入后续短期记忆读取。

### 2. 浏览器与反查手机

- 新增浏览器及反查手机中的浏览器页面，支持相关浏览、搜索与收藏记录。
- 新增独立的反查浏览器配置绑定，支持单独设置 API、预设、世界书和翻译。
- 完善三种反查手机方式：用户邀请、角色申请、角色偷偷查看。
- 三种反查均会在 Chat 生成灰色记录卡，可查看开始时间、结束时间及实际查阅内容。
- 删除 Chat 中对应的反查记录后，会撤销该次原始查阅事件的短期记忆来源，不影响后续独立产生的聊天记录。

### 3. Chat 与好友关系

- 联系人角色卡新增 Chat 网名设置，与聊天资料保持同步。
- 新增好友名片推荐功能，可向角色介绍已有好友并建立关系线。
- 删除已发送的推荐名片时，同步解除由该名片建立的关系线。
- 角色推荐好友后产生的申请新增「取消／忽略／添加」选项。
  - **取消**：终止本次推荐的后续流程。
  - **忽略**：暂不添加，之后可能在 1–3 天内再次申请。
  - **添加**：接受申请并建立好友关系。
- 修复群语音和群视频挂断后自动触发 AI 回复的问题，挂断后直接返回群聊。

### 4. 界面与交互优化

- 调整生图相册详情页的字号和行距，改善提示词、说明与按钮的阅读体验。
- 优化独立 App 绑定页面，按照桌面应用展示配置入口。
- 统一独立 App 绑定页面的图标样式。
- 保留反查浏览器的独立绑定入口，避免与普通浏览器配置混淆。

### 5. 其他修复

- 优化跨应用事件的自动总结与来源记录。
- 改善历史事件、多人互动及匿名身份的记忆处理。
- 减少重复上下文与无效记忆注入，提高不同应用之间的互动连贯性。

## 1.8.1：iCity补写与音乐卡修正

普通历史补写按批次随机分配公开、好友可读和私密，保证有可直接查看的日记；没有iCity好友关系时改用公开范围生成，不自动添加好友。生成前就确定范围，明确的私密补写入口保留。补写先查当天日历、聊天和已知事件，再参考此前14天背景、共享记录及日期允许的长期／核心记忆。当天资料不足时结合核心设定和截至当时的近期情况写日常或心绪。完成后显示分类数量并可进入相应角色日记本。

角色主页恢复显示对你可读的好友日记；选择头像改用主题色外圈，保留头像原色和透明度。日记无配图时也可正常分享。两版音乐卡两颗点保留0.30.1／1.4.1镜像修正，插件仍0.13.1。
