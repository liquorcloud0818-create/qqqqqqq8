# 1.5 更新记录

- **Chat／Lysn 多图消息**：新增滑动洗牌效果；缩小卡片叠放角度和间距，优化左右对称排列，避免图片超出屏幕。
- **图片展开与显示**：折叠预览从图片中心取景；展开后横图、方图、竖图保持各自比例，并按发送方头像一侧对齐；调整展开按钮的位置与样式。
- **单图与实况照片**：优化图片大小、圆角和等比例显示，减少拉伸与多余留白。
- **AI 配图**：增加各平台「优先文字图／自动生图」偏好，优化文字图及图片生成的处理方式。
- **Lysn 泡泡**：调整艺人面向多位粉丝交流时的生成提示，缩小消息时间和已读标识。
- **相册**：完善生成图片保存到设备的功能。
- **Chat 截图**：优化多选聊天截图的气泡显示和保存提示。
- **电话与短信**：优化部分设置开关的样式、字号及间距。
- **全屏特效**：恢复设置入口，新增默认关闭的总开关；关闭时停止播放特效，并且不向单聊、群聊注入特效提示词；开启后按已启用的特效生效。
